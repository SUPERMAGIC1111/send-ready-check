# Send-ready Check (early prototype)

Paste the HTML of a web page and get a short German list of what to fix before you send the page to a customer: title, meta description, one H1, image alt texts, vague link text, call to action, contact, Impressum and Datenschutz links, placeholder text, language, viewport.

- Runs entirely in your browser. The code you paste is not sent or stored. No account, no AI, no cookies, no external scripts.
- Checks technical basics only. Not legal advice (the Impressum and Datenschutz checks only look for links).
- Early prototype. Feedback welcome.
